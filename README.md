# TV Auto X5

TV Auto X5 是 TV Auto 的兼容分支，面向系统 WebView 较旧、网页播放能力较弱的设备。它保留标准版的全部主要功能，并额外内置腾讯 TBS X5 离线内核，用于改善部分老旧设备上的网页兼容性。

当前版本：**v6.0-x5**  
包名：`mulin.tvauto.pro.x5`  
最低系统：**Android 5.0**

---

## 与标准版的关系

| 版本 | 推荐场景 |
| --- | --- |
| TV Auto | 默认推荐，体积小，依赖系统 WebView，适合大多数设备 |
| TV Auto X5 | 当系统 WebView 太旧、网页打不开或无法播放时尝试，安装包更大 |

TV Auto X5 与标准版使用不同包名，可以同时安装，互不覆盖。  
如果标准版已经能稳定使用，通常没有必要改用 X5 版。

---

## X5 分支特点

- 内置离线 X5 core，不依赖首次联网下载
- 同时内置 32 位和 64 位 ARM core，启动时会按设备 ABI 自动选择
- 首次启动时提供完整引导，自动完成 X5 准备流程
- 日常启动成功后只做轻量提示，不反复展示配置页面
- 提供 `X5 管理` 页面，可查看当前实际内核状态并进行调试
- 与标准版可以共存，便于在同一设备上对比效果

> X5 版主要服务于兼容性，不代表所有网站都会因此可播放。网页本身的登录限制、站点策略和播放器实现仍然可能影响结果。

---

## 保留的标准功能

- 内置默认频道，首次安装即可使用
- 遥控器、键盘和触摸屏操作
- 扫码进入手机管理页
- 频道新增、删除、恢复默认、清空、批量导入和导出
- 用户脚本新增、编辑、删除、导入和导出
- 半透明加载提示层
- 原始网页模式

## 播放与管理

### 日常播放

- 上 / 下键切换频道
- OK / 右键打开频道列表
- 菜单键打开频道管理
- 数字键直接跳转到指定频道

### 手机管理

打开频道管理窗口后，左侧会显示二维码和局域网地址。手机与电视连接同一 Wi‑Fi 后，扫码即可进入手机管理页。关闭频道管理窗口后，手机管理服务会自动停止。

手机端支持：

- 新增、删除、恢复默认和清空频道
- 批量导入 `.txt`
- 导出当前频道列表为 `.txt`
- 检测更新
- 用户脚本管理
- 用户脚本 `.json` 导入和导出

### 原始网页模式

遇到需要登录、授权或操作原网页的网站时：

- 全屏播放下连续按两次左键进入
- 或在频道管理中点击 `原始网页`
- 进入后会显示站点原始页面，并保留常驻提示
- 按返回键回到播放模式

原始网页模式更适合触屏或接入鼠标后使用；复杂网页通常不适合只靠遥控器完成操作。

## 遥控器操作

| 按键 | 功能 |
| --- | --- |
| 上 / 下 | 切换上一频道 / 下一频道 |
| OK / 右 | 打开右侧频道列表 |
| 左 | 连续按两次进入原始网页模式 |
| 菜单 | 打开频道管理 |
| 数字键 | 直接输入频道号 |
| 返回 | 播放模式下双击退出；原始网页模式下返回播放 |

## 频道导入格式

频道导入和导出均使用纯文本 `.txt`，每个频道以英文分号结尾：

```txt
"频道名称","频道地址";
```

示例：

```txt
"CCTV-1 综合","https://tv.cctv.com/live/cctv1/";"江苏卫视","https://live.jstv.com/";
```

导出的文件名会自动带上实际日期，便于备份。

## X5 内核说明

- 当前分支使用腾讯 TBS SDK，并内置离线 X5 core
- 支持 ARM 设备：`armeabi-v7a` 与 `arm64-v8a`
- 不支持使用 `x86 / x86_64` 模拟器来验证离线 X5 是否真正生效
- 首次安装后，应用会自动准备 X5；成功后可在 `X5 管理` 页面查看当前内核
- 若显示 `当前内核：X5`，说明正在使用 X5；若显示系统 WebView，则表示当前没有切换成功或设备不适配

---

## 使用须知

- 默认频道仅作示例用途，不保证长期可用，也不保证适用于所有地区
- 请用户自行核实并添加合规频道
- TV Auto X5 只负责整理和展示用户访问的网页内容，不提供直播内容本身
- 使用过程中请遵守当地法律法规，开发者不承担因用户自行添加内容而产生的法律责任
