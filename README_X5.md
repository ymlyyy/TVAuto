# TV Auto X5 分支说明

当前目录是 TV Auto 的 X5 兼容分支。面向普通用户的完整说明请直接查看 `README.md`。

## 分支要点

- 包名：`mulin.tvauto.pro.x5`
- 版本：`6.0-x5`
- 最低系统：Android 5.0
- 使用腾讯 TBS X5 WebView
- 内置 ARM 32 位与 ARM 64 位离线 core，按设备 ABI 自动选择
- 首次启动通过引导页自动准备 X5
- 提供 X5 管理与调试入口
- 与标准版可以同时安装

## 适用场景

当标准版依赖的系统 WebView 过旧，导致网页无法打开、视频无法播放或兼容性明显较差时，再尝试本分支。若标准版已经稳定可用，优先保留标准版即可。
